# محاسبة بقالتي — مشروع أندرويد قابل للبناء

هذه **حزمة مصدر فعلية** وليست ملف APK جاهزًا. تضم واجهة التطبيق داخل `app/src/main/assets/index.html` وغلاف Android WebView يفتحها محليًا، مع دعم JavaScript وDOM Storage حتى تعمل الواجهة دون إنترنت وتستطيع حفظ بياناتها محليًا.

## ما الذي تحتويه؟
- واجهة عربية RTL باسم «محاسبة بقالتي»، مع دفتر حركة صندوق مشتق، طباعة إيصال حراري 80mm، فلترة تاريخية للفواتير، وتنبيه للنسخ الاحتياطي.
- ملفات Android Gradle وملف `MainActivity.java`.
- فتح روابط الاتصال وواتساب خارج التطبيق.
- سير عمل GitHub Actions لبناء APK تجريبي تلقائيًا عند رفع المشروع وتشغيل الإجراء.

## بناء APK دون تثبيت أدوات على الهاتف
1. فك ضغط ZIP على كمبيوتر.
2. ارفع محتويات مجلد المشروع إلى مستودع GitHub جديد، وليس ملف ZIP نفسه فقط.
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build Android APK** ثم **Run workflow**.
5. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل الملف من **Artifacts** باسم `Mohasabat-Bagalati-debug-apk`.
6. فك ضغط ملف Artifact وستجد `app-debug.apk`.

## نتيجة التدقيق والقيود الحالية
راجع ملف `فحوص_الحزمة.txt` لمعرفة الفحوص التي اجتازت والقيود التي ما زالت تمنع اعتماد المحاسبة التجارية. اجتياز فحص الصياغة والحسابات الجزئية لا يثبت صحة جميع تدفقات العمل.

## تنبيه صريح قبل الاستخدام التجاري
- هذه نسخة أولية قابلة للبناء وليست إصدارًا محاسبيًا معتمدًا.
- لم يُنتج هذا الأرشيف APK ولم يُختبر على هاتف حقيقي حتى الآن.
- البيانات مخزنة محليًا في WebView؛ لا تمسح بيانات التطبيق قبل تصدير نسخة احتياطية.
- لا توجد في هذه النسخة قراءة باركود بالكاميرا، أو مرتجعات مكتملة، أو دفتر قيود مزدوج، أو سجل تدقيق غير قابل للمحو. دفتر الصندوق الحالي كشف مشتق من الحركات وليس دفتر قيود مستقلًا، ولا يتضمن رصيدًا افتتاحيًا للصندوق أو وقتًا دقيقًا لكل حركة. تكلفة البيع التاريخية تُحفظ في فواتير البيع الجديدة وفق متوسط التكلفة المرجح وقت البيع؛ الفواتير القديمة التي لا تملك هذه البيانات تُظهر تحذيرًا ولا تُخمن تكلفتها من السعر الحالي. لا يوجد ضمان لاستعادة البيانات بعد حذف التطبيق إلا إذا احتُفظ بملف النسخة الاحتياطية خارج التطبيق.
- اختبر فواتير البيع والشراء والديون والخصومات والنسخ الاحتياطي ببيانات تجريبية قبل إدخال حسابات المتجر الحقيقية.
